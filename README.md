# ShopEasy: E-Commerce Capstone

A responsive e-commerce web app built with HTML, CSS, and vanilla JavaScript. It features simulated login, a searchable product catalog, full CRUD, and a persistent cart.

**Live demo:** https://YOUR-SITE.netlify.app
**Repository:** https://github.com/YOUR-USERNAME/shopeasy-ecommerce-capstone

## Features

- **Simulated authentication:** log in with any email and a 4+ character password; the session persists after refresh
- **Interactive catalog:** live search and category filter
- **Full CRUD:** logged-in users can add, edit, and delete products
- **Shopping cart:** add and remove items, quantity tracking, running total
- **Persistent state:** products, cart, and session are saved in localStorage
- **Responsive design:** works on phones and desktops
